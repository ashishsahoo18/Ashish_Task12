# TuteDude MERN Stack – JavaScript: Compound Interest Calculation

## Files Included
- `index.html` – Page that links the CSS and JavaScript files
- `style.css` – Basic styling
- `script.js` – JavaScript program that calculates compound interest
- `README.md` – This file

## How to Run
1. Unzip the folder.
2. Open `index.html` in Chrome or Firefox.
3. Press F12 and open the **Console** tab to see the output.

## Formula Used
```
A = P (1 + r/n) ^ (n * t)
```

| Symbol | Meaning | Value used |
|--------|---------|-----------|
| A | Final amount | calculated |
| P | Principal | 10000 |
| r | Annual interest rate | 0.05 (5%) |
| n | Times compounded per year | 4 |
| t | Time in years | 3 |

## Output
```
The compound interest after 3 years is: 11607.55
```
(The result is printed with `console.log()`.)

## Concepts Used
- Variables (`var`)
- Operators (`*`, `+`, `/`)
- `Math.pow()` for the power
- `toFixed(2)` to round to 2 decimal places
- `console.log()` to display the output
